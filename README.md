# 青竹txt书籍下载

书籍 TXT 批量下载器（Windows 桌面 App）——从维基文库、识典古籍、CTEXT 三大站点抓取公有领域书籍文本，一键导出 UTF-8 纯文本，用于本地阅读、AI 有声书制作（ebook2audiobook / EmotiVoice / Alexandria 等）。

## 功能特性

- **模式一 · 书名搜索**：输入书名，勾选数据源，跨站检索；结果表格支持多选，一键下载全书 TXT
- **模式二 · 链接下载**：粘贴任意书籍目录链接，程序自动识别站点、解析全部章节，批量导出全书
- **内置 3 个数据源**：维基文库（zh.wikisource.org）、识典古籍（shidianguji.com）、CTEXT（ctext.org/zh）
- **文本清洗**：剔除网页标签、脚注标记、页眉页脚、多余空行
- **强制 UTF-8 编码**：防止 TTS 工具读取乱码
- **可选分章节导出**：按章节拆分为独立 txt 文件，适配 AI TTS 分批合成
- **反爬策略**：UA 随机伪装、0.8~1.2 秒请求间隔、单章最多重试 2 次、失败自动跳过不崩溃
- 实时进度条 + 带时间戳的日志窗口

## 环境要求

- Windows 10 / 11 64 位
- Python 3.9+（已安装 PyQt6 环境则无需再装）

## 安装与运行

```bash
pip install -r requirements.txt
python app.py
```

依赖清单见 [requirements.txt](requirements.txt)：PyQt6 / requests / beautifulsoup4。

## 使用说明

启动后先阅读并确认免责声明，然后进入主界面：

1. **顶部**勾选数据源（可多选）
2. **Tab1 按书名搜索下载**
   - 输入书名（例：三国演义）→ 点击【开始搜索】
   - 在结果表格勾选书籍 → 点击【下载选中书籍】
3. **Tab2 根据网页链接下载全书**
   - 粘贴书籍目录页链接 → 点击【解析目录】
   - 确认章节总数后点击【开始下载全书 TXT】
4. **下载设置**：输出目录（默认 `D:\书籍TXT下载\`）、自动清洗、分章节导出
5. 底部日志实时显示进度，完成后点击【打开输出文件夹】

### 输出示例

## 项目结构

```
青竹小说-Windows\
├─ app.py                      # 程序入口（免责弹窗 → 主窗口）
├─ requirements.txt            # 依赖清单
├─ core\
│   ├─ http_client.py          # HTTP 封装：UA 伪装、请求间隔、重试、反爬识别
│   ├─ text_cleaner.py         # 通用文本清洗
│   ├─ file_manager.py         # 安全文件名、UTF-8 保存
│   ├─ downloader.py           # 下载调度（QThread 后台执行）
│   └─ models.py               # 数据模型与异常
├─ adapters\
│   ├─ base.py                 # 统一适配器接口
│   ├─ wikisource.py           # 维基文库
│   ├─ shidianguji.py          # 识典古籍
│   └─ ctext.py                # CTEXT
└─ ui\
    ├─ disclaimer.py           # 免责声明弹窗
    └─ main_window.py          # 主窗口
```

## 已知限制

- **CTEXT**：该站点当前对程序化请求启用了 Cloudflare 人机验证，程序会自动提示【网站访问受限，请稍后重试】。可稍后再试或改用浏览器阅读。
- **识典古籍**：书籍主页 `/book/{id}` 不输出服务端目录数据，URL 模式下请粘贴**任意章节链接**（程序会自动还原全书目录）；搜索模式下下载不受影响。

## 打包为独立 exe（可选）

